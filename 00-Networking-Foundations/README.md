# Cisco Network Basics Home Lab

A complete beginner-friendly home lab series using **Cisco Packet Tracer**.  
This repository documents step-by-step solutions and explanations for fundamental networking labs.

These labs cover essential concepts required for anyone starting a career in networking, network administration, or preparing for Cisco certifications (CCNA / Junior Network Analyst path).

---

## What You Will Learn

- Physical device connections (coaxial + Ethernet)
- Home wireless router configuration
- DHCP server setup and IP addressing
- Network Address Translation (NAT)
- MAC vs IP addressing behavior
- Traffic flow in routed vs non-routed networks
- Client-server communication (HTTP, DNS, FTP)
- Remote access using Telnet and SSH
- Essential troubleshooting commands (`ipconfig`, `ping`)

## How to Use This Repository

1. Install **Cisco Packet Tracer** (free from [NetAcad](https://www.netacad.com)).
2. Clone or download this repository.
3. Open any lab folder.
4. Read the `README.md` for that lab.
5. Open the `.pka` file in Packet Tracer and follow the steps.
6. Compare your results with the documented solution.
