# ForensicsContest Puzzle #3 — Ann's AppleTV

## 1. Case Overview

### Scenario

Ann and Mr. X have established a new base of operations. The provided network capture contains activity generated by Ann's AppleTV. The investigation focuses on reconstructing the AppleTV's network and application activity from packet-level evidence.

### Investigation Objective

The objective was to analyze the network capture associated with Ann's AppleTV and determine:

1. AppleTV MAC address
2. HTTP User-Agent
3. First four incremental searches
4. First movie clicked
5. Movie trailer URL
6. Second movie clicked
7. Purchase price
8. Final complete search term

## 3. Investigation Methodology

The investigation was performed using Wireshark against the challenge-provided PCAP.

The following workflow was used:

* PCAP integrity verification using the challenge-provided MD5
* Identification of the known AppleTV host
* Ethernet-layer inspection for the MAC address
* HTTP protocol analysis
* User-Agent extraction
* Chronological HTTP request analysis
* Incremental search reconstruction
* Movie-selection traffic correlation
* HTTP stream reconstruction
* Analysis of compressed HTTP responses
* XML metadata extraction
* Identification of `preview-url`
* Identification of `price-display`
* Final search reconstruction

### Key Wireshark Filters

Host-focused traffic:

```text
ip.addr == 192.168.1.10
```

HTTP GET requests:

```text
ip.addr == 192.168.1.10 && http.request.method == "GET"
```

Incremental movie searches:

```text
ip.addr == 192.168.1.10 && http.request.uri contains "incrementalSearch"
```

HTTP traffic:

```text
ip.addr == 192.168.1.10 && http
```

The `/b/ss/applesuperglobal/` requests were identified as associated analytics traffic and were not counted as separate user searches.

## 4. Findings

### Finding 1 — AppleTV MAC Address

**Question:** What is the MAC address of Ann's AppleTV?

**Evidence:**

The Ethernet header of traffic originating from the known AppleTV host `192.168.1.10` was inspected in Wireshark.

**Finding:**

```text
00:25:00:fe:07:c4
```

**Analysis:**

The MAC address provides the Layer-2 identifier associated with the AppleTV. Correlating the MAC address with the known IP address helps establish the device identity within the capture.

---

### Finding 2 — HTTP User-Agent

**Question:** What User-Agent string did Ann's AppleTV use?

**Evidence:**

An HTTP request from the AppleTV contained:

```http
User-Agent: AppleTV/2.4
```

**Finding:**

```text
AppleTV/2.4
```

**Analysis:**

The User-Agent provides an application/device fingerprint and allows HTTP activity to be associated with the AppleTV software generating the requests.

---

### Finding 3 — First Four Search Terms

**Question:** What were the first four search terms?

The AppleTV generated incremental search requests through:

```text
/WebObjects/MZSearch.woa/wa/incrementalSearch
```

Observed requests included:

```http
GET /WebObjects/MZSearch.woa/wa/incrementalSearch?media=movie&q=h HTTP/1.1
```

```http
GET /WebObjects/MZSearch.woa/wa/incrementalSearch?media=movie&q=ha HTTP/1.1
```

```http
GET /WebObjects/MZSearch.woa/wa/incrementalSearch?media=movie&q=hac HTTP/1.1
```

```http
GET /WebObjects/MZSearch.woa/wa/incrementalSearch?media=movie&q=hack HTTP/1.1
```

**Finding:**

| Order | Search term |
| ----: | ----------- |
|     1 | `h`         |
|     2 | `ha`        |
|     3 | `hac`       |
|     4 | `hack`      |

**Analysis:**

The AppleTV performed incremental searches as characters were entered. Each request exposed the current search string through the `q` parameter.

This demonstrates how application-layer traffic can reveal user input progressively, even when a user does not submit the complete term in a single request.

---

### Finding 4 — First Movie

**Question:** What was the first movie clicked?

**Finding:**

**Hackers**

**Analysis:**

The movie selection was correlated with the HTTP activity following the `hack` search sequence. The associated movie-detail traffic identified the first selected title as *Hackers*.

---

### Finding 5 — Movie Trailer URL

**Question:** What full trailer URL was defined by `preview-url`?

The movie metadata response contained the following trailer URL:

```text
http://a227.v.phobos.apple.com/us/r1000/008/Video/62/bd/1b/mzm.plqacyqb..640x278.h264lc.d2.p.m4v
```

**Finding:**

```text
http://a227.v.phobos.apple.com/us/r1000/008/Video/62/bd/1b/mzm.plqacyqb..640x278.h264lc.d2.p.m4v
```

**Analysis:**

The URL was recovered from the movie metadata rather than from the initial HTTP request itself. The relevant HTTP response was XML and used gzip content encoding, requiring HTTP stream/response analysis to expose the application data.

---

### Finding 6 — Second Movie

**Question:** What was the second movie clicked?

**Finding:**

**Sneakers**

**Analysis:**

Subsequent AppleTV movie-detail traffic was analyzed chronologically to identify the second movie selection. The associated movie was *Sneakers*.

---

### Finding 7 — Purchase Price

**Question:** What purchase price was defined by `price-display`?

The decoded XML movie metadata contained:

```xml
<key>price-display</key><string>$9.99</string>
```

**Finding:**

```text
$9.99
```

**Analysis:**

The response used gzip compression:

```text
Content-Encoding: gzip
```

and was identified as XML:

```text
Content-Type: text/xml
```

The `price-display` value was therefore extracted after reconstructing/decompressing the HTTP response.

The value represents the purchase price requested by the puzzle.

---

### Finding 8 — Final Search Term

**Question:** What was the last full search term?

The final incremental search sequence was reconstructed from successive HTTP requests.

Observed values included:

```text
iknowyourewa
iknowyourewatchingm
iknowyourewatching
iknowyourewatchingme
```

**Finding:**

```text
iknowyourewatchingme
```

**Analysis:**

The final value was identified as the last incremental search request in the sequence. This demonstrates that the complete user input can be reconstructed by following incremental application requests chronologically.

## 6. Analyst Assessment

The PCAP demonstrates that substantial user and application activity can be reconstructed from network traffic.

The AppleTV could be identified through a combination of IP, MAC address, and HTTP User-Agent information. HTTP requests then provided sufficient application-layer evidence to reconstruct incremental movie searches and correlate those searches with movie selections.

The investigation also demonstrated the importance of analyzing HTTP response bodies. Significant evidence, including the trailer URL and purchase price, was contained in XML returned by the application rather than in simple HTTP headers.

The incremental-search behavior was particularly significant from a forensic perspective. The search input was transmitted progressively, allowing the complete final search term to be reconstructed from multiple requests.
